Goal: Switchbard opens to a useful last-known view on the first native frame, then updates each surface as live probes complete.

The startup cache is a versioned, bounded, local read model. Current config, repository files, Git, OS process probes, and GitHub observations remain authoritative. Cached-only state can inform the display but cannot authorize mutations, process signals, dispatch, or destructive worktree actions.

Delivery is sequenced as vertical slices that begin with an executable cold-start journey and end with macOS and Linux evidence.
