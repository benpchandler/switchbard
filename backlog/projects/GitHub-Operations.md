Canonical GitHub delivery-control surface for tracked repositories. Ops > Pull requests owns pull-request visibility and bounded actions; Digest may only mirror items already represented there. GitHub remains authoritative for pull-request, check, review, merge, release, and deployment facts, while Switchbard retains local task outcome authority. Version 1 includes status, open diff, comment, approve or request changes, rerun failed checks, update branch, auto-merge, and merge. It excludes admin bypass, ruleset edits, branch deletion, and inline code review.
